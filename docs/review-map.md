# Next Experiment: map for jury review

**Question:** Which gene-screen signal deserves follow-up, and which evidence would change that choice?

Start the local browser with `python scripts/serve-demo.py`. Open `/panel` for six-gene decision support, then `/` for one complete recorded Omnigent investigation. The panel uses fixed rules and a curated source snapshot. Both pages display saved results; actual agents execute through `scripts/run-lab.sh` with a supported provider login.

## Follow one complete loop

1. **Question and hypothesis:** UBA3's high aggregate signal may represent a reproducible effect or guide-specific instability. [Initial count record](https://github.com/Arag0n1421/next-experiment/blob/main/runs/live/452fda4c1e084b9d9b1ae4fea2e1e39f.json).
2. **Two tests and selection:** compare guide sensitivity with IL6 context. The saved decision records expected learning, feasibility, qualitative cost and why guide sensitivity was selected. [Decision record](https://github.com/Arag0n1421/next-experiment/blob/main/runs/live/9640dbe6abbb44d7b72e9141e4c1f1ac.json).
3. **Executed result:** UBA3's no-IL6 approximate score is 4.174; one guide omission changes it to −0.055. All three omissions are reported. [Executed analysis](https://github.com/Arag0n1421/next-experiment/blob/main/runs/live/d8edc9f95f0c4934ae9b4358fd89e98f.json).
4. **Updated decision:** request more guide-resolved evidence before immediate prioritization. [Updated action and proposed test](https://github.com/Arag0n1421/next-experiment/blob/main/runs/live/9640dbe6abbb44d7b72e9141e4c1f1ac.json).
5. **Next experiment:** confirm suppression with independent guides, then assess senescence, MSC identity and fitness with controls and biological repeats. This is a proposed design, not a completed experiment or validated protocol.

## What would strengthen the scientific claim next?

A locked multi-case evaluation against the fixed-rule baseline could measure whether agents improve source-faithful next decisions under a matched budget. Independent biological measurements would be needed to establish the intended phenotype. An end-to-end timed workflow would be needed to attribute acceleration to Omnigent orchestration rather than checklist computation.

The source package omits credentials, the large public matrix and raw account-linked sessions. The matrix is separately downloadable with hash verification.
